# Referenzstimmen für Chatterbox

Kurze Ausschnitte (je ~13 s, 24 kHz mono, FLAC) aus frei lizenzierten Sprachdatensätzen.
Chatterbox übernimmt daraus nur die Klangfarbe der Stimme.

| Datei | Quelle | Lizenz |
|---|---|---|
| `thorsten-*` | Thorsten Müller, *Thorsten-Voice Dataset 2021.06 emotional*, https://zenodo.org/records/5525023 | CC BY 4.0 |
| `kerstin` | Rhasspy, *dataset-voice-kerstin*, https://github.com/rhasspy/dataset-voice-kerstin | CC0 1.0 |
| `mls-<Sprecher>` | V. Pratap et al., *MLS: A Large-Scale Multilingual Dataset for Speech Research* (German, LibriVox), https://huggingface.co/datasets/facebook/multilingual_librispeech | CC BY 4.0 |
